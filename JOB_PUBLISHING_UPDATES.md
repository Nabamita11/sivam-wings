Sivam Wings — Job Publishing Portal Updates

Changes in this version:
- Replaced the Department dropdown in the job publishing form with an editable Department / Team text field.
- Added a Compensation, Perks & Benefits multiline field. Enter each item on a new line; values are saved with the job and shown wherever job benefits are displayed.
- Added an Edit action to each published job card. Editing opens the form prefilled with the current job data and saves changes against the existing job ID.
- Kept the Delete action and job status controls.
- Retained the existing About section without the founder photo.

To run locally: install Node.js if needed, open this folder in VS Code, run `npm install`, then `npm run dev`. Open http://localhost:3000/.

Note: The package installation/build could not be completed in the build environment, so please test locally before deploying. Keep your existing private .env file safe; do not upload secrets to a public repository.
